# ColorOS WIFI感知

作者 **酷安@NVMEX夜莺**

[酷安主页](https://www.coolapk.com/u/1060215)

在 Magisk 或 KernelSU 管理器中从本地选择模块 ZIP，安装时按音量键选择功能，安装后重启。音量＋选择“核心及流体云通知（推荐）”，音量－选择“仅核心”；仅核心模式会移除流体云 DEX，不启动界面子进程。模块卡片的「操作」按钮继续用于切换阈值。

模块需要 Android 10 或更新版本，守护进程在开机后独立运行。使用模块时可关闭欧加网络助手里的弱信号断开开关，避免两边重复触发。

默认阈值为 **−80 dBm**。仅在 `PowerManager.isInteractive()` 为真且只有一个 Wi-Fi 连接时监控。系统事件触发检查并合并重复请求；因为 RSSI 广播可能只反映等级变化，也可能无法送达独立 root 进程，保留亮屏时 **7 秒兜底读取**，不主动扫描。

首次达到或低于阈值时，开始 **7 秒倒计时**，两种安装模式都在验证期间每秒复查。启用流体云时主动展开卡片，进度条递减，开关默认开启，**关闭开关立即断开当前接入点**。息屏会撤回卡片并取消采样、倒计时及待处理断开；亮屏重新读取当前 AP，重新计时。信号恢复、切换接入点、修改阈值或网络断开也会取消原判断。

倒计时结束或用户手动操作时，重新核对交互状态、当前网络、BSSID、RSSI、阈值、冷却和事件代次，才请求断开 AP。系统 Wi-Fi 总开关保持开启，Android 可以自动重连。每次实际断开调用后至少冷却 60 秒；冷却期间不周期读取 RSSI，只在连接变化、亮屏或用户刷新时读取快照。多个 Wi-Fi 网络、无 Wi-Fi 或仅移动数据时暂停采样。模块记录原弱 AP 的重连次数，不修改已保存网络的自动连接配置。

## Web 管理面板

在支持模块 WebUI 的 KernelSU/兼容管理器中打开模块页面，可调整 −100 至 −20 dBm 阈值、设置流体云通知并查看状态与累计运行指标。仅核心安装没有流体云 DEX，面板会提示重新安装后才能开启通知。原有模块「操作」按钮继续切换阈值。

页面只在打开或手动刷新时请求状态，不启动 HTTP 服务，不后台轮询。普通 Magisk 管理器需使用兼容的 WebUI 宿主；命令行与操作按钮继续可用。

本次自动测试、手机测试边界与功耗分析见 [低功耗优化报告](docs/low-power/REPORT.md)。本地运行 `./test.ps1` 验证策略、生命周期、竞态与 WebUI。操作计数和 CPU ticks 不能直接换算为 mAh。

## 流体云与测试

只需要 root，不需要 LSPosed、额外 APK 或修改 SystemUI。已在一加 PLK110 / ColorOS 17.0.0.105 验证原生卡片、强提醒、开关和进度模板。此通道使用 ColorOS 私有接口，其他版本是否支持需实机验证；界面子进程失败会记录日志，原有 AP 断开策略继续运行。

监控进程保持 root，短时界面子进程在加载 DEX 后切换为系统 UID，通过系统已有的流体云 Provider 投放卡片。开关仅向监控进程回传当前会话事件；监控进程再次核对 AP、阈值和信号后才执行断开。收到网络断开确认后，显示“WIFI信号弱，已手动断开。”或“WIFI信号弱，已自动断开。”，立即收起为顶部胶囊，保留 15 秒后撤回；点击胶囊仍可查看结果。模块停用或监控进程退出时，通过管道关闭界面子进程。

安装后可执行以下命令测试 UI 和开关回调，**测试不会断开 Wi-Fi**：

```sh
su -c 'sh /data/adb/modules/coloros_wifi_sense/demo.sh'
```

首次弱信号使用强提醒主动展开；同一倒计时的后续更新只更新内容和进度。卡片标识固定，避免重复叠加。

## 调阈值

点模块卡片的「操作」，可在 −75、−80、−85、−90 dBm 之间循环。也可在 Root 终端里设为 −100 至 −20 dBm 的任意整数。新值在下一次采样时生效，更新模块时沿用已有阈值。

```sh
su -c 'sh /data/adb/modules/coloros_wifi_sense/settings.sh -83'
```

省略末尾的数字可读取当前阈值。运行日志使用 `ColorOsWifiSense` 标签。

## 打包模块

使用 JDK 17、Android SDK Platform 36 和 Build Tools 36.0.0。以下命令从项目根目录运行，ZIP 输出到 `build/`。

```powershell
./build.ps1 -AndroidSdk 'D:/Android/SDK' -Jdk 'C:/Program Files/Java/jdk-17'
```
